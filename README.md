# AnimeDub

Программа для Windows, которая озвучивает аниме на нужном языке голосами самих персонажей. Предназначена для личного просмотра.

Как она работает: отделяет голоса от музыки, распознаёт японскую речь, делает разговорный перевод через Claude, озвучивает каждую реплику голосом персонажа (образцом служит его же оригинальная фраза, поэтому сохраняется часть эмоции) и собирает видео с двумя дорожками: дубляж и оригинал.

## Где взять exe

Сборка запускается сама при каждом изменении кода в репозитории (через 3–5 минут).
Готовый файл публикуется во вкладке **Releases**, а последняя версия всегда доступна по ссылке:

https://github.com/alexbl2802-hue/Anime/releases/latest/download/AnimeDub.exe

Там же лежит `AnimeDub.zip` с тем же exe внутри, а приложение для телефона — по ссылке:

https://github.com/alexbl2802-hue/Anime/releases/latest/download/AnimeDub.apk

## Первый запуск

- Windows может показать предупреждение SmartScreen, потому что программа без цифровой подписи. Нажми «Подробнее → Выполнить в любом случае». Антивирус иногда реагирует на exe, собранные PyInstaller, это известное ложное срабатывание.
- Нажми **«Установить компоненты»**. Программа сама скачает Python, ffmpeg, PyTorch с поддержкой видеокарты и нейросети в `%LOCALAPPDATA%\AnimeDub` (winget не нужен). Общий процент установки и прогресс каждого скачивания видны над журналом. Скачается около 10 ГБ, это займёт 20–60 минут. Делается один раз.
- Получи ключ API на console.anthropic.com и вставь его в поле «Ключ Claude API». Перевод серии стоит несколько центов. Ключ хранится только у тебя на компьютере, в `config.json`.

## Работа с серией

1. **Выбрать…** — укажи файл серии (mkv, mp4).
2. Опиши персонажей и их манеру речи. Это сильнее всего влияет на живость перевода. Например:
   ```
   Школьная комедия.
   Харука — вспыльчивая, резкая, саркастичная.
   Сота — тихий отличник, вежливый, запинается.
   ```
   Для следующих серий того же тайтла описание подставится само.
3. **«1. Распознать и перевести»**. После этого откроется редактор перевода. Красным отмечены слишком длинные реплики: их придётся ускорять, лучше сократить.
4. **«2. Озвучить и собрать видео»**. Результат появится рядом с серией как `имя_dub_ru.mkv`. Переключить дорожку на оригинал можно в плеере (VLC, MPC-HC).

Если потом поправить перевод в редакторе и снова нажать «2», переозвучатся только изменённые реплики.

## Просмотр на телефоне (Android)

1. Скачай `AnimeDub.apk` на телефон и установи его. Android попросит разрешить установку из этого источника.
2. На компьютере в AnimeDub включи галочку **«Смотреть серии в приложении на Android»**. Windows спросит про брандмауэр: разреши доступ (отметь обе галочки — частные и общественные сети).
3. В приложении на телефоне введи адрес и ключ, которые показаны под галочкой.

Каждая папка с готовыми сериями (`*_dub_*.mkv`) — это одно аниме. Папки, где ты делал дубляж, добавляются сами, другие можно добавить кнопкой **«Добавить папку с сериями…»**. Обложки — кадры из самих серий, их делает компьютер.

В приложении:
- **Боковая вкладка справа** (кнопка ☰): «Все аниме», «История просмотра», «Сменить компьютер».
- **Все аниме** — карточки с кадрами из серий и большая карточка «Продолжить просмотр».
- **Страница аниме** — список серий с отметками «Просмотрено» и «Остановился на …».
- **Плеер**: двойное касание слева/справа — перемотка на 10 с, свайп по левой половине — яркость, по правой — громкость, «Пропустить опенинг» (+1:25), скорость 0.5–2×, озвучка «Дубляж» / «Оригинал», субтитры, блокировка экрана, следующая серия (и автопереход в конце).

**Смотреть вне дома.** Установи бесплатный [Tailscale](https://tailscale.com/download) на компьютер и на телефон и войди в оба под одним аккаунтом. Тогда под галочкой появится адрес вида `100.x.x.x:8765 (Tailscale)` — введи его в приложении, и серии будут открываться откуда угодно, где есть интернет. Трафик идёт напрямую между твоими устройствами и шифруется. Компьютер при этом должен быть включён, а AnimeDub — запущен.

Если серия не воспроизводится: телефоны часто не умеют декодировать видео в 10-битном H.264 (бывает в фансаб-релизах). HEVC (H.265) обычно работает.

## Структура проекта

- `app.py` — окно программы
- `dub.py` — конвейер обработки (можно запускать и из консоли)
- `server.py` — раздача готовых серий на телефон
- `android/` — приложение для Android
- `.github/workflows/build.yml` — автоматическая сборка exe
