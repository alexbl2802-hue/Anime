# AnimeDub

Программа для Windows, которая озвучивает аниме на нужном языке голосами самих персонажей. Предназначена для личного просмотра.

Как она работает: отделяет голоса от музыки, распознаёт японскую речь, делает разговорный перевод через Claude, озвучивает каждую реплику голосом персонажа (образцом служит его же оригинальная фраза, поэтому сохраняется часть эмоции) и собирает видео с двумя дорожками: дубляж и оригинал.

## Где взять exe

Сборка запускается сама при каждом изменении кода в репозитории (через 3–5 минут).
Готовый файл публикуется во вкладке **Releases**, а последняя версия всегда доступна по ссылке:

https://github.com/alexbl2802-hue/Anime/releases/latest/download/AnimeDub.exe

Там же лежит `AnimeDub.zip` с тем же exe внутри, а приложение для телефона — по ссылке:

https://github.com/alexbl2802-hue/Anime/releases/latest/download/AnimeDub.apk

## Первый запуск

- Windows может показать предупреждение SmartScreen, потому что программа без цифровой подписи. Нажми «Подробнее → Выполнить в любом случае». Антивирус иногда реагирует на exe, собранные PyInstaller, это известное ложное срабатывание.
- Нажми **«Установить компоненты»**. Программа сама скачает Python, ffmpeg, PyTorch с поддержкой видеокарты и нейросети в `%LOCALAPPDATA%\AnimeDub` (winget не нужен). Общий процент установки и прогресс каждого скачивания видны над журналом. Скачается около 15 ГБ (вместе с бесплатным переводчиком), это займёт 30–90 минут. Делается один раз.
- **Переводчик.** По умолчанию — «Локально — бесплатно»: перевод делает нейросеть Qwen 2.5 через [Ollama](https://ollama.com) прямо на твоём компьютере, ключ и оплата не нужны. Модель подбирается под память видеокарты (8 ГБ → 7B, 12–16 ГБ → 14B, 24 ГБ → 32B). Чтобы качество было ближе к Claude, перевод идёт в три шага: словарь имён и терминов (`glossary.json` в папке работы), перевод по сценам и редакторский проход «как живая речь». На видеокарте серия переводится примерно за 10–25 минут.
- Вариант «Claude — лучше качество» переводит точнее и живее, но нужен ключ API с console.anthropic.com (перевод серии стоит несколько центов). Ключ хранится только у тебя на компьютере, в `config.json`.

## Как программа старается сделать озвучку похожей на оригинал

- **Нет «немых» мест.** Если реплику не удалось распознать или озвучить (крик, речь под музыкой), в дорожке «Дубляж» там звучит оригинальный японский голос, а не тишина. Отключить: `--no-original-gaps` при запуске `dub.py` из консоли.
- **Голоса персонажей.** Программа сама группирует реплики по голосам и для каждого персонажа собирает образец из его лучших реплик (до 15 секунд). Озвучка берёт и общий образец (тембр точнее), и саму реплику (эмоция момента). Группы сохраняются в `speakers.json` в папке работы.
- **Проверка перевода.** Сдвинутые, пустые, с иероглифами или латиницей реплики, потерянные имена и одинаковые переводы соседних реплик переводятся заново по одной; реплики, которые не влезают по времени, модель сокращает.
- **Песни** на английском в начале и конце серии не переводятся и не озвучиваются.

Чтобы серия прошла заново со всеми улучшениями, удали её папку `work_<название серии>`.

## Видеокарта с 4 ГБ памяти

Программа сама определяет память видеокарты. Если её меньше 6 ГБ (например, ноутбучная RTX 3050 на 4 ГБ), включается экономный режим:
- распознавание речи работает в сжатом формате (int8) — вдвое меньше видеопамяти почти без потери точности;
- отделение голоса идёт короткими кусками, а при нехватке памяти продолжается на процессоре;
- перед каждым этапом видеопамять освобождается, модель перевода выгружается перед озвучкой;
- если озвучке не хватает памяти, она продолжается на процессоре с той же реплики — уже озвученное не теряется;
- модель перевода Qwen 2.5 7B частично работает на процессоре, поэтому перевод серии занимает примерно 25–50 минут.

Серия целиком на такой видеокарте озвучивается примерно за 1–2 часа. В журнале в начале распознавания видно: «Видеопамять: 4.0 ГБ — экономный режим».

## Работа с серией

1. **Выбрать…** — укажи файл серии (mkv, mp4).
2. Опиши персонажей — **по строке на каждого, в виде «Имя — кто это, как говорит»**. Это сильнее всего влияет на перевод: имена отсюда подсказываются распознаванию речи (чтобы Whisper писал их правильно) и закрепляются в словаре перевода (чтобы «Ирука» не стал «дельфином»). Например:
   ```
   Школьная комедия.
   Харука — вспыльчивая, резкая, саркастичная.
   Сота — тихий отличник, вежливый, запинается.
   ```
   Для следующих серий того же тайтла описание подставится само.
3. **«1. Распознать и перевести»**. После этого откроется редактор перевода. Красным отмечены слишком длинные реплики: их придётся ускорять, лучше сократить.
4. **«2. Озвучить и собрать видео»**. Результат появится рядом с серией как `имя_dub_ru.mkv`. Переключить дорожку на оригинал можно в плеере (VLC, MPC-HC).

Если потом поправить перевод в редакторе и снова нажать «2», переозвучатся только изменённые реплики.

## Просмотр на телефоне (Android)

1. Скачай `AnimeDub.apk` на телефон и установи его. Android попросит разрешить установку из этого источника.
2. На компьютере в AnimeDub включи галочку **«Смотреть серии в приложении на Android»**. Windows спросит про брандмауэр: разреши доступ (отметь обе галочки — частные и общественные сети).
3. В приложении на телефоне введи адрес и ключ, которые показаны под галочкой.

Каждая папка с готовыми сериями (`*_dub_*.mkv`) — это одно аниме. Папки, где ты делал дубляж, добавляются сами, другие можно добавить кнопкой **«Добавить папку с сериями…»**. Обложки — кадры из самих серий, их делает компьютер.

В приложении:
- **Боковая вкладка справа** (кнопка ☰): «Все аниме», «История просмотра», «Сменить компьютер».
- **Все аниме** — карточки с кадрами из серий и большая карточка «Продолжить просмотр».
- **Страница аниме** — список серий с отметками «Просмотрено» и «Остановился на …».
- **Плеер**: двойное касание слева/справа — перемотка на 10 с, свайп по левой половине — яркость, по правой — громкость, «Пропустить опенинг» (+1:25), скорость 0.5–2×, озвучка «Дубляж» / «Оригинал», субтитры, блокировка экрана, следующая серия (и автопереход в конце).

**Озвучка с телефона.** В боковой вкладке есть пункт **«Озвучка»**. Там видны все серии из папок AnimeDub на компьютере: нажми **«Озвучить»**, выбери язык и при желании опиши персонажей. Можно и **загрузить видео с телефона** — оно попадёт в `Видео\AnimeDub\<название аниме>` на компьютере и сразу встанет в очередь. Вся работа идёт на видеокарте ноутбука, на телефоне видны этап и проценты, задание можно отменить. Готовая серия сама появится во «Все аниме». Серии озвучиваются по одной; пока идёт озвучка с телефона, кнопки дубляжа в окне программы ждут. Перевод делается целиком без редактора — поправить его можно потом в программе на компьютере и снова нажать «2».

**Смотреть вне дома.** Установи бесплатный [Tailscale](https://tailscale.com/download) на компьютер и на телефон и войди в оба под одним аккаунтом. Тогда под галочкой появится адрес вида `100.x.x.x:8765 (Tailscale)` — введи его в приложении, и серии будут открываться откуда угодно, где есть интернет. Трафик идёт напрямую между твоими устройствами и шифруется. Компьютер при этом должен быть включён, а AnimeDub — запущен.

Если серия не воспроизводится: телефоны часто не умеют декодировать видео в 10-битном H.264 (бывает в фансаб-релизах). HEVC (H.265) обычно работает.

## Сервер без ноутбука (бесплатно, без видеокарты)

AnimeDub можно поставить на облачный сервер с Linux — тогда ноутбук не нужен совсем: телефон сам загружает серии на сервер, запускает озвучку и смотрит готовое. Подойдёт бесплатный сервер **Oracle Cloud «Always Free»** (процессор ARM, 4 ядра, 24 ГБ памяти, до 200 ГБ диска) или любой другой сервер с Ubuntu 22.04/24.04 и хотя бы 8 ГБ памяти.

**Главное ограничение:** без видеокарты всё считает процессор, поэтому одна серия озвучивается **примерно 6–12 часов** на 4 ядрах (быстрее на более мощном сервере). Удобно ставить серии в очередь на ночь — сервер работает круглосуточно и обрабатывает их по одной.

### Установка на Oracle Cloud

1. Зарегистрируйся на [oracle.com/cloud/free](https://www.oracle.com/cloud/free/). Нужна банковская карта для проверки личности, деньги за бесплатные ресурсы не списываются. Oracle работает не во всех странах — если регистрация не проходит, подойдёт любой другой сервер с Ubuntu.
2. **Compute → Instances → Create instance**:
   - Image: **Ubuntu 24.04**;
   - Shape: **Ampere → VM.Standard.A1.Flex**, 4 OCPU и 24 ГБ памяти (это бесплатно);
   - Boot volume: 100–200 ГБ (серии занимают место).
   Если пишет «Out of capacity», попробуй позже или другую зону (Availability domain).
3. Открой сервер: кнопка **Cloud Shell** вверху консоли → `ssh ubuntu@<публичный IP сервера>` (или любой SSH-клиент с ключом, который Oracle дал при создании).
4. Выполни одну команду — она поставит всё сама (30–60 минут):
   ```
   curl -fsSL https://raw.githubusercontent.com/alexbl2802-hue/Anime/ccr-311f9029-7rdvqa/server/install.sh | bash
   ```
5. В конце скрипт покажет ссылку **Tailscale** — открой её на телефоне и войди тем же аккаунтом, что и в приложении [Tailscale](https://tailscale.com/download) на телефоне. Так телефон и сервер связаны напрямую и с шифрованием, открывать порты в облаке не нужно.
6. Скрипт напечатает **адрес** (`100.x.x.x:8765`) и **ключ** — введи их в приложении AnimeDub (☰ → «Сменить компьютер»).

Дальше всё как с ноутбуком: ☰ → **«Озвучка»** → «Загрузить видео с телефона» или «Озвучить». Видео хранятся на сервере в `~/animedub/videos/<название аниме>/`.

Полезные команды на сервере:
- адрес и ключ ещё раз: `~/animedub/venv/bin/python ~/animedub/app/headless.py --show`
- что сейчас делает сервер: `sudo journalctl -u animedub -f`
- обновить AnimeDub: снова выполнить команду установки из шага 4
- модель перевода побыстрее (качество ниже): `~/animedub/venv/bin/python ~/animedub/app/headless.py --model qwen2.5:3b && ollama pull qwen2.5:3b && sudo systemctl restart animedub`

Что настроено для работы без видеокарты: распознавание моделью large-v3-turbo (на процессоре в несколько раз быстрее large-v3 почти без потери точности), все ядра процессора, бесплатный перевод Qwen 2.5 7B через Ollama, ключ из 16 символов и блокировка адреса на 10 минут после 10 неверных ключей подряд.

## Структура проекта

- `app.py` — окно программы
- `dub.py` — конвейер обработки (можно запускать и из консоли)
- `server.py` — раздача готовых серий на телефон
- `jobs.py` — очередь озвучки, запущенной с телефона
- `headless.py`, `server/install.sh` — AnimeDub-сервер без окна для облака
- `android/` — приложение для Android
- `.github/workflows/build.yml` — автоматическая сборка exe
